# LINE 群組票務管理機器人 v2

放進 LINE 群組，幫你管理代購搶票的場次、訂單、繳費與拓元新場次偵測。

---

## ✅ 這版修了什麼 / 新增什麼

- **修正：登記不了訂單** — 場次改用「純數字編號」，下單只要打 `下單 3 7880 2`，手機也好打。
- **人人可新增場次**，重複（同團＋同場次＋同演出日）會自動提醒已存在。
- **同團不同日 = 不同場次**，各自獨立編號。
- **實名制說明自由填寫**，不限固定字詞。
- **搶票前 3 天**自動提醒繳「票款」＝票面 ＋ 拓元手續費（每張預設 $200，可改）。
- **搶票後 2 天**自動提醒繳「服務費」（每場可不同價，**只有你 OWNER 能設**）。
- **繳費登記**：你可標記誰已繳／未繳，**月底自動再提醒沒繳的人**。
- **拓元偵測**：台灣新場次全部通知；國外只通知符合關鍵字的（預設 aespa / IVE / BTS / ITZY，隨時可改）。

## 🚀 安裝步驟

1. 安裝 Node.js 18+，然後：
   ```bash
   npm install
   cp .env.example .env   # 填入你的金鑰與 OWNER_ID
   npm start
   ```
2. 到 [LINE Developers](https://developers.line.biz/) 建一個 **Messaging API** channel，
   把 `LINE_CHANNEL_ACCESS_TOKEN`、`LINE_CHANNEL_SECRET` 填進 `.env`。
3. Webhook URL 設成 `https://你的網域/webhook`（本機測試可用 ngrok）。
4. 關閉「自動回覆訊息」、開啟「Webhook」。
5. 把機器人加進群組，隨便發一句話 → 看終端機 log 印出你的 `userId`，
   把它填進 `.env` 的 `OWNER_ID`，重啟。
6. 在群組輸入 `設定主群組`，之後所有提醒與拓元通知都會發到這個群。

> 資料會存在 `data.json`，重啟不會掉。雲端部署（如 Render/Railway）請把這檔放在持久磁碟，或改 `DATA_FILE` 路徑。

## 📖 指令速查

### 人人可用
| 指令 | 說明 |
|---|---|
| `查場次` | 列出所有場次與編號 |
| `場次 3` | 看 #3 詳情 |
| `新增場次 團名 場次 演出日 搶票日 票價,票價 實名制說明` | 建立場次 |
| `下單 3 7880 2` | 登記 #3、票價7880、2張 |
| `取消下單 3 7880 1` | 取消 |
| `我的訂單` | 看自己所有登記與應繳 |
| `查名單 帳號` | 查黑白名單 |
| `關鍵字` | 看國外偵測關鍵字 |
| `幫助` / `規章` | 指令表 / 交易須知 |

### 管理員
`訂單彙整 3`、`加白名單/加黑名單 帳號 備註`、`移除白名單/移除黑名單`、`查白名單/查黑名單`

### ⭐ 主管理員（OWNER）專屬
| 指令 | 說明 |
|---|---|
| `設定服務費 3 7880:2500 6880:2000 4880:1500` | 依票價分區設服務費（只有你能設） |
| `設定服務費 3 全部 2000` | 所有票價區同價 |
| `查服務費 3` | 查看某場服務費設定（人人可看） |
| `設定手續費 3 200` | 改拓元手續費 |
| `查繳費 3` | 看 #3 每個人繳費狀態（含序號） |
| `登記繳費 3 1 票款` | 把序號1的人「票款」標記已繳 |
| `登記繳費 3 1 服務費` | 標記服務費已繳 |
| `取消繳費 3 1 票款` | 改回未繳 |
| `新增關鍵字 SEVENTEEN` / `移除關鍵字 BTS` | 改國外偵測關鍵字 |
| `開啟偵測` / `關閉偵測` | 開關拓元偵測 |
| `設定主群組` | 指定提醒要發的群 |

## ⏰ 自動排程

- 每天 **10:00（台灣時間）** 檢查：搶票前3天票款提醒、搶票後2天服務費提醒、月底未繳提醒。
- 每 **30 分鐘** 偵測拓元新場次。

可在 `app.js` 的 `cron.schedule(...)` 調整時間。

## ⚠️ 拓元偵測注意事項（重要）

拓元 `tixcraft.com` 會對程式存取回 **403**（屬於「擋標頭／TLS 指紋」型防爬）。本專案抓取順序如下：

1. **got-scraping**（預設，免費、輕量、模擬瀏覽器指紋）— 多數情況可直接過，不用額外設定。
2. 若仍被擋（拓元若上 Cloudflare JS 驗證），改用**代抓 API**：到 [scraperapi.com](https://www.scraperapi.com/) 註冊（有免費額度），拿到 API key 後在 Render 環境變數新增：
   - `SCRAPER_API_KEY` = 你的 key
   - 若還是被擋，再加 `SCRAPER_PREMIUM` = `1`（會消耗較多額度，請降低偵測頻率）

**驗證方式**：在群組輸入 `測試拓元`（限主管理員），機器人會立刻抓一次並回報成功筆數或錯誤訊息。

**偵測頻率**：預設每 2 小時一次，可用環境變數 `TIX_CRON` 調整（cron 格式，例如 `0 */6 * * *` 為每 6 小時）。若用 ScraperAPI 免費額度，建議調成 6～12 小時以節省額度。

> 若 `測試拓元` 顯示「解析到 0 筆」，代表抓得到頁面但拓元 HTML 改版了，調整 `src/commands/tixcraft.js` 的 `parseEvents()` 選擇器即可（目前抓 `a[href*="/activity/detail/"]`）。台灣 vs 國外用 `TW_HINTS` 地名判斷，可自行增補。

## 🗂️ 檔案結構

```
app.js                  入口：webhook + 排程 + 推播 + 權限
src/
  store.js              資料儲存（JSON 持久化）
  helpers.js            日期/金額工具
  router.js             指令分派
  reminders.js          票款/服務費/月底提醒
  commands/
    events.js           新增/查/刪 場次
    orders.js           下單/取消/我的訂單/彙整
    payments.js         服務費設定 + 繳費登記
    lists.js            黑白名單
    tixcraft.js         拓元偵測 + 關鍵字
    info.js             幫助/規章
```
